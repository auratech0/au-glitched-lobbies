### Contributing to au-glitched-lobbies

Thank you for your interest in contributing to **au-glitched-lobbies**! To maintain code quality, security, and project integrity, all contributors must follow these guidelines. 

### Strict AI-Generated Code Policy

We enforce a **zero-tolerance policy** regarding the misuse of Artificial Intelligence (AI) tools (such as ChatGPT, GitHub Copilot, Claude, etc.) in code submissions. 

* **Allowed Use:** You may use AI tools **only** as an assistant to help debug, optimize, or fix specific bugs within code that *you* have written.
* **Prohibited Use:** You **cannot** use AI to generate the entire contribution, full functions, or major blocks of code.

### Consequences of Violation

If a Pull Request (PR) or contribution is found to consist entirely or largely of AI-generated code: 

1. **Immediate Block:** The Pull Request will be closed and blocked immediately.
2. **No Appeals:** This decision is final. No appeals or justifications will be reviewed.
3. **Permanent Ban:** The contributor will be **permanently banned** from interacting with, opening issues, or contributing to this repository.

We value authentic, human-written logic. If you use AI for debugging, ensure the final structure and logic are fundamentally your own. 

### How to Contribute

### 1. Reporting Bugs & Suggesting Features

* Check the **Issues** tab to ensure the topic has not been discussed yet.
* Open a new issue using a clear, descriptive title.
* Provide steps to reproduce the bug or a detailed explanation of the feature.

### 2. Submitting Changes (Pull Requests)

* **Fork** the repository and create your branch from main.
* Ensure your code adheres to the existing style of the project.
* Write clear, concise commit messages.
* Open a Pull Request with a detailed description of the changes made.

### Enforcement and Authority

The repository maintainers reserve the right to utilize specialized detection tools or engineering judgment to identify AI-generated code. By submitting a contribution, you agree to these terms.
