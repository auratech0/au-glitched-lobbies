### Security Policy

### Supported Versions

We actively monitor and fix security vulnerabilities only for the latest main branch of this repository. Older forks, snapshots, or unauthorized distributions are not supported. 


|     Version    |   Support   |
| :-------------:| :---------: |
|  Among Us v18  |  Supported  |
|  Among Us v17> | Unsupported |


### Reporting a Vulnerability

**Please do not open public GitHub Issues for security vulnerabilities.** Publicly disclosing a security flaw can expose users to immediate risk. 

If you discover a security vulnerability within **au-glitched-lobbies**, please report it responsibly using one of the following methods: 

### 1. Private Vulnerability Reporting (Preferred)

GitHub provides a built-in private reporting feature for repository owners. 

* Go to the **Security** tab of this repository.
* Under the *Vulnerability reporting* section, click **Report a vulnerability**.
* Fill out the details privately. This ensures only the repository maintainers can see the report.

### 2. Direct Contact

If the private reporting tool is unavailable, you can contact the repository owner directly via the contact methods listed on the [auratech0 GitHub profile](https://github.com/auratech0). 

### Our Response Process

Once a valid security report is received, the maintainers will: 

1. **Acknowledge:** Respond to your report within 48 hours to confirm receipt.
2. **Investigate:** Analyze the issue to verify the impact and determine a fix.
3. **Resolve:** Develop a patch to resolve the vulnerability.
4. **Publish:** Release an updated version of the code and, if necessary, publish a GitHub Security Advisory detailing the fix.

Thank you for helping keep the **au-glitched-lobbies** community safe and secure!
